# Ising island outline

Source: F. Kos, D. Poland, D. Simmons-Duffin and A. Vichi, *Precision Islands in the Ising and O(N) Models*, arXiv:1603.04436 (2016), Figure 1, inset; Lambda = 43.

https://arxiv.org/abs/1603.04436

The 12 polygon vertices in `ising-island.json` were recovered from the blue filled vector path in the published PDF (page 4, drawing path 66). The inset axis ticks were used to convert PDF coordinates to Delta_sigma and Delta_epsilon. This is a digitization of the published figure outline, not the authors' raw numerical scan data. The website displays a zoomed version with explicit axis values.

The particle motion between the equation and the island is a visual transition, not a numerical bootstrap calculation. The front displays the identical-real-scalar crossing sum rule with the squared OPE coefficient. The back is the mixed-correlator Ising result identified above.
